# shopping-list-app

의존성 없는 단일 HTML 파일로 만든 쇼핑 리스트 앱. 빌드나 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 기능

- **추가** — 입력 후 `추가` 버튼 또는 Enter. 빈 값과 공백만 입력한 값은 무시하고, 앞뒤 공백은 잘라서 저장합니다.
- **체크** — 체크박스 또는 품목 이름을 클릭해 토글. 완료 항목은 취소선 처리됩니다.
- **삭제** — 각 항목 오른쪽 `×` 버튼.
- **체크한 항목 비우기** — 완료된 항목만 한 번에 정리합니다.
- 목록은 `localStorage`에 자동 저장되어 브라우저를 닫았다 열어도 유지됩니다. 저장이 막힌 환경(시크릿 모드 등)에서도 화면 동작은 그대로입니다.
- 다크 모드와 모바일 화면 폭을 지원합니다.

## 실행

```
index.html
```

파일을 더블클릭하거나 브라우저로 열면 됩니다.

## 테스트

jsdom 위에 실제 `index.html`을 올려 사용자 조작을 재현하는 테스트 22개가 있습니다.

```
npm install
npm test
```

추가·삭제·체크 기능과 카운터, 비우기 버튼 상태, localStorage 저장/복원, 손상된 저장값 처리, HTML 삽입 방지를 검증합니다.

## 개발 설정

헤더의 `last updated` 날짜는 pre-commit 훅이 자동으로 갱신합니다. 저장소를 처음 클론했다면 한 번만 실행해 주세요.

```
git config core.hooksPath .githooks
```

이후 `index.html`이 포함된 커밋마다 날짜가 커밋 당일로 맞춰집니다.
